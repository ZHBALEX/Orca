Orca 三张涡结构图
================

运行入口：run__vortexAtlas.py
打开这个文件，在 main() 开头的“用户设置”中修改，然后直接运行。
不需要通过命令行传参数，也不需要修改 config.py。

设置区包括：
1. 数据路径、输出位置、相位与帧号；锚点和场数据必须是同一相位。
2. 坐标原点与 L，标签（TEV₂、RV⁺/RV⁻）、配色、字体和色标。
3. 三张图各自的坐标范围、刻度、标注位置、面板尺寸。
4. 输出格式、dpi、是否显示图窗，以及选择重画哪些图。

原始数据 ID W2 对应图中的 TEV₂，保留这个映射以追溯既有分析数据。
范围和标注位置仍使用求解器坐标输入，显示时转换为 x*、y*、z*。

文件分工：
  run__vortexAtlas.py        用户设置与运行流程
  read_vortex_atlas.py       读取现有锚点、流场、几何缓存
  fn___plotVortexAtlas.py    三张图的绘图函数；接收数组和参数，返回 figure
  fn___vortexStyle.py        坐标、字体、配色、标注及混合图层设置
  fn___exportVortexAtlas.py  保存 PNG/PDF/SVG、检查 SVG 分层、记录输入哈希

代码库中仅保留上述 5 个 Python 文件和 2 个说明文件。

依赖：NumPy、SciPy、Matplotlib。
当前 main() 中 dependency_paths 使用本机已有依赖；常规环境已安装时可设为 []。
本入口重用已经提取的数据，不重新计算涡分类或力学结论。

SVG/PDF：每个分图的科学绘图内容嵌入图片，文字、坐标轴、刻度、箭头可编辑。
报告生成与研究历史脚本在上述归档目录，当前绘图入口不依赖该归档。
